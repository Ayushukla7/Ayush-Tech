## 🛰️ Overview & Design Concept

This website combines a **Google Earth satellite flight experience**, **NASA-inspired orbital telemetry**, and a **high-tech futuristic developer HUD** to showcase Ayush Shukla's projects, technical skills, and professional journey.

### 🌟 Key Highlights
- **Cinematic Satellite Descent (Three.js + GSAP)**: Starts in deep space at geostationary orbit (~35,786 km), rotates to align with India, and executes a hypersonic dive straight into the destination sector (Delhi-NCR / Lucknow region, `28.67° N, 77.45° E`).
- **Skip Intro & Accessibility**: One-click skip button and automatic compliance with `prefers-reduced-motion`.
- **Full-Screen 3D Orbit Mode**: Free flight rotation and zoom controls allowing recruiters to inspect the procedural Earth globe, specular oceans, city night lights, and coordinate beacons.
- **Web Audio API Synthesizer**: Zero-latency tactical radar pings, atmospheric descent whooshes, and mechanical key sounds synthesized in real-time in the browser.
- **Interactive Technical Skills Dashboard**: Organized into Programming (Python, Java, C, C++), Frontend (HTML, CSS, JS, React), Backend (Node.js, Django), Database (SQL), and Developer Tools (Git, GitHub, VS Code).
- **Featured Projects**:
  1. **VacciTrack / Medi-Vahak** — Child immunization management platform (National Hackathon Runner-Up, 1st Prize in Healthcare Innovation).
  2. **SkillLedger** — Blockchain-based skill verification and micro-certification platform concept.
  3. **Personal Portfolio** — Interactive 3D Earth digital identity and engineering showcase.
  4. **WorkRadar** — Predictive task & workforce analytics platform (88% delay accuracy, -45% query latency).
- **Professional Timeline & Leadership**: Co-Founder at ZenYukti, Capgemini Student Ambassador, Elixir Tech Community Manager (2,000+ members), Technovation Club UI Lead.
- **Printable Resume Dossier**: Built-in resume viewer formatted for single-click clean PDF export (`window.print()`).

## 🛠️ Technology Stack

- **Frontend Core**: React 18, Vite
- **3D Graphics & WebGL**: Three.js, Custom Procedural Shaders, Canvas Texturing
- **Cinematic Motion**: GSAP (GreenSock Animation Platform)
- **Styling & UI**: Tailwind CSS, PostCSS, Lucide React Icons
- **Audio Synthesis**: Native Web Audio API (`AudioContext`)
- **Typography**: Orbitron, Space Grotesk, JetBrains Mono

## 🚀 Local Development

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Dev Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Production Build
```bash
npm run build
```
Generates optimized code-split bundles in `dist/`.

## 🌐 Deployment to Vercel / Netlify

### Deploy on Vercel:
```bash
npm install -g vercel
vercel
```
