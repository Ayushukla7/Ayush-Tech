## ✨ Overview

An ultra-modern, high-performance developer portfolio featuring an interactive **3D Digital Lanyard ID Badge** (with physical tilt, 360° rotation, flip to inspect credentials & barcode) paired with a clean **Bento Grid** containing a **Social Hexagon/Circle Grid** and a **Latest Projects Showcase**.

### 🌟 Key Features
- **3D Interactive Digital ID Lanyard Badge (Three.js)**:
  - Realistic plastic protective sleeve with specular sheen and reflections.
  - Metallic top lanyard clip and transparent strap loop.
  - Physics-based mouse tracking and 3D tilting with spring inertia.
  - Free drag-to-rotate on both axes.
  - One-click badge flip to inspect barcode, magnetic stripe, and verified credentials.
- **Vibrant Ambient Aurora Glow**:
  - Soft blurred multi-color peripheral gradient (emerald green, royal blue, magenta/pink) surrounding the dark Bento deck.
- **Cross-Grid Texture**:
  - Subtle micro-dot crosshairs pattern behind the ID badge card.
- **Honeycomb / Circular Social Link Grid**:
  - LinkedIn, GitHub, Live Web Portfolio, Official Resume, Direct Email, and 250+ DSA Solutions.
- **Latest Projects Showcase**:
  - **VacciTrack / Medi-Vahak** — Child Immunization Management (National Hackathon 2nd Runner-Up, 1st in Healthcare).
  - **WorkRadar** — Predictive Task Analytics & 0–100 Delay Risk Engine (88% accuracy, 45% latency cut).
  - **AYUSH-UI** — Modern Frontend & UI/UX Design System (60 FPS micro-animations).
  - **SkillLedger** — Blockchain-Based Skill Verification Concept.
  - **Personal Portfolio** — 3D Digital Pass Developer Identity.
- **Tabbed Explorer**:
  - Toggle between **Projects**, **Technical Skills** (Programming, Frontend, Backend, Databases, Tools), **Leadership & Awards**, and **About / Direct Contact**.
- **Interactive Project Case Studies**:
  - Modal with detailed problem statement, tech stack badges, key features, and live links.
- **Printable Resume Dossier**:
  - Built-in printable resume modal formatted for clean 1-page PDF export (`window.print()`).

## 🛠️ Local Development

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Dev Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build for Production
```bash
npm run build
```
